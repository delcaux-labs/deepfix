% ---------------------- COLUMN 1: Why & How (0.24) --------------------------
\begin{column}{0.24\textwidth}

\begin{posterblock}[Motivation]
  \fontsize{28}{36}\selectfont\color{BodyText}\justifying
  Unlike traditional software with deterministic code execution paths:
  \vspace{4mm}
  \begin{itemize}[leftmargin=10mm, itemsep=6mm, label={\textcolor{TUMAccent}{\textbullet}}]
    \item \textbf{Fail Silently} --- ML models exhibit gradual degradation or silent bias rather than throwing explicit crashes or stack traces.
    \item \textbf{Fragmented Debugging} --- Developers must manually correlate symptoms across disjointed data quality checks, training logs, and metrics.
    \item \textbf{Model-Restricted} --- Conventional property and metamorphic testing are bound to specific algorithms and fail on opaque neural networks.
    \item \textbf{No Actionable Remedies} --- Existing diagnostic tools focus purely on bug detection, offering no automated fix suggestions.
  \end{itemize}
\end{posterblock}

\vspace{12mm}

\begin{highlightblock}[Research Question]
  \fontsize{30}{38}\selectfont\color{TUMDarkBlue}
  \centering\itshape
  Can we develop a unified approach that tests \textbf{all components of the ML workflow} (data, split, model) and provides a bug report with \textbf{actionable fix suggestions}?
\end{highlightblock}

\vspace{12mm}

  \fontsize{26}{32}\selectfont\color{BodyText}\justifying
  The DeepFix SDK integrates seamlessly into existing MLOps environments.

\begin{posterblock}[Example Findings (Industrial Case Study)]
  \fontsize{24}{30}\selectfont\color{BodyText}\justifying
  Validated in an industrial food waste image classification project at Delcaux Labs in partnership with \textbf{L. Stroetmann Großverbraucher GmbH \& Co. KG}. The underlying dataset is openly available on Hugging Face: \href{https://huggingface.co/datasets/AI-ServicesBB/food-waste-dataset}{\color{TUMBlue}\texttt{AI-ServicesBB/food-waste-dataset}}. DeepFix successfully surfaced critical silent production bugs:

  \vspace{4mm}
  \begin{columns}[T]
    \begin{column}{0.48\textwidth}
      \begin{tcolorbox}[
        enhanced, colback=white, colframe=SeverityCritical,
        boxrule=2pt, arc=4pt, left=6mm, right=6mm, top=4mm, bottom=4mm,
        title={\color{white}\fontsize{22}{26}\selectfont\bfseries CRITICAL --- Data Partitioning Failure},
        colbacktitle=SeverityCritical,
      ]
        \fontsize{20}{24}\selectfont
        \textbf{Evidence:} Combined checks surfaced that label drift Cram\'{e}r's V\,=\,0.92 (exceeding the 0.15 limit) and 75\% of test set labels were entirely absent from training.

        \vspace{3mm}
        \textcolor{TUMBlue}{\textbf{Fix:}} Halt model development immediately and recreate the train--test split using stratified sampling.
      \end{tcolorbox}
    \end{column}
    \hfill
    \begin{column}{0.48\textwidth}
      \begin{tcolorbox}[
        enhanced, colback=white, colframe=SeverityHigh,
        boxrule=2pt, arc=4pt, left=6mm, right=6mm, top=4mm, bottom=4mm,
        title={\color{white}\fontsize{22}{26}\selectfont\bfseries HIGH --- Image Acquisition Drift},
        colbacktitle=SeverityHigh,
      ]
        \fontsize{20}{24}\selectfont
        \textbf{Evidence:} Multiple image properties failed Kolmogorov-Smirnov drift tests: Brightness (KS=0.42), RMS Contrast (KS=0.50), and Color channels (Red=0.83, Green=0.82, Blue=0.96).

        \vspace{3mm}
        \textcolor{TUMBlue}{\textbf{Fix:}} Standardize image collection protocols and apply color/intensity normalization to align characteristics.
      \end{tcolorbox}
    \end{column}
  \end{columns}
\end{posterblock}

\begin{posterblock}[Limitations \& Next Steps]
  \fontsize{20}{25}\selectfont\color{BodyText}\justifying
  While DeepFix significantly accelerates ML workflow auditing:
  \vspace{3mm}
  \begin{itemize}[leftmargin=6mm, itemsep=2.5mm, label={\textcolor{TUMAccent}{\textbullet}}]
    \item \textbf{Limitations:} Relies primarily on Deepchecks for stage 1 checks (additional failure modes are expressible by extending the artifact schemas); introduces higher latency and compute costs than traditional linters due to multi-agent LLM analysis.
    \item \textbf{Grounding \& Compliance:} Data privacy is protected by supporting on-premise execution with self-hosted LLMs, ensuring sensitive artifacts never leave the organization.
    \item \textbf{Future Work:} Conduct a 30-participant usability study to measure the adoption rate of recommendations; expand the stage 1 analyzers with complementary unit-level and artifact-level testing tools; curate additional best practices in \texttt{deepfix-kb}.
  \end{itemize}
\end{posterblock}
