% ---------------------- COLUMN 1: Why & How (0.27) --------------------------
\begin{column}{0.27\textwidth}

\begin{posterblock}[Motivation]
  \fontsize{28}{36}\selectfont\color{BodyText}\justifying
  Unlike traditional software with deterministic code execution paths:
  \vspace{4mm}
  \begin{itemize}[leftmargin=10mm, itemsep=8mm, label={\textcolor{TUMAccent}{\textbullet}}]
    \item \textbf{ML models fail silently} --- they do not crash or output explicit stack traces, instead exhibiting gradual degradation or silent bias.
    \item \textbf{Debugging is highly fragmented} --- developers must manually correlate symptoms across disjointed data quality checks, training logs, and model performance metrics, increasing cognitive load.
    \item \textbf{Rigid testing is model-restricted} --- conventional property testing, metamorphic testing, and formal verification are bound to specific algorithm classes and struggle with opaque neural networks.
    \item \textbf{Statistical jargon is uninterpretable} --- existing test outputs report statistical violations in complex terminology without explaining the root causes to practitioners.
    \item \textbf{Lack of actionable remedies} --- tools focus solely on bug detection, providing no guidance on how to fix the identified bugs.
  \end{itemize}
\end{posterblock}

\vspace{\colsep}

\begin{highlightblock}[Research Question]
  \fontsize{30}{38}\selectfont\color{TUMDarkBlue}
  \centering\itshape
  Can we develop a unified approach that tests \textbf{all components of the ML workflow} (data, split, model) and provides a bug report with \textbf{actionable fix suggestions}?
\end{highlightblock}

\vspace{\colsep}

\begin{posterblock}[How It Works --- 3 Lines of Code]
  \fontsize{26}{32}\selectfont\color{BodyText}\justifying
  The DeepFix SDK integrates seamlessly into existing MLOps environments.

  \vspace{6mm}
  \begin{tcolorbox}[
    enhanced, colback=TUMDarkBlue!5, colframe=TUMDarkBlue!40,
    boxrule=1.5pt, arc=4pt, left=8mm, right=8mm, top=6mm, bottom=6mm,
  ]
    {\fontsize{24}{30}\selectfont\ttfamily\color{TUMDarkBlue}
    from deepfix\_sdk import DeepFixClient \\
    client = DeepFixClient(timeout=360) \\
    train\_data = ...
    val\_data = ...
    result = client.get\_diagnosis( \\
       train\_data=train\_data, \\
       test\_data=val\_data, \\
       language="english",\\
    )
    }
  \end{tcolorbox}

  \vspace{6mm}
  {\fontsize{24}{30}\selectfont\color{LightText}
  DeepFix encapsulates raw artifact parsing on the client, maintaining compliance by keeping data private, while exporting structured metadata to the server. Open source --- Apache 2.0 license.}
\end{posterblock}

\begin{column}{0.27\textwidth}

\begin{posterblock}[Example Findings (Industrial Case)]
  \fontsize{26}{32}\selectfont\color{BodyText}\justifying
  Validated in an industrial food waste image classification project at Delcaux Labs in partnership with \textbf{L. Stroetmann Großverbraucher GmbH \& Co. KG}. The underlying dataset is openly available on Hugging Face: \href{https://huggingface.co/datasets/AI-ServicesBB/food-waste-dataset}{\color{TUMBlue}\texttt{AI-ServicesBB/food-waste-dataset}}.

  DeepFix surfaced critical bugs that would have required extensive manual visual review to find:

  \vspace{4mm}
  \begin{tcolorbox}[
    enhanced, colback=white, colframe=SeverityCritical,
    boxrule=2pt, arc=4pt, left=8mm, right=8mm, top=5mm, bottom=5mm,
    title={\color{white}\fontsize{24}{28}\selectfont\bfseries CRITICAL --- Data Partitioning Failure},
    colbacktitle=SeverityCritical,
  ]
    \fontsize{22}{26}\selectfont
    \textbf{Evidence:} Combined evidence from Deepchecks surfaced that the label drift Cram\'{e}r's V\,=\,0.92 (far exceeding the 0.15 threshold) and 75\% of test set labels were entirely absent from training.

    \vspace{3mm}
    \textcolor{TUMBlue}{\textbf{Fix:}} Halt model development immediately and recreate the train--test split using stratified sampling.
  \end{tcolorbox}

  \vspace{4mm}

  \begin{tcolorbox}[
    enhanced, colback=white, colframe=SeverityHigh,
    boxrule=2pt, arc=4pt, left=8mm, right=8mm, top=5mm, bottom=5mm,
    title={\color{white}\fontsize{24}{28}\selectfont\bfseries HIGH --- Image Acquisition Drift},
    colbacktitle=SeverityHigh,
  ]
    \fontsize{22}{26}\selectfont
    \textbf{Evidence:} Multiple image properties failed Kolmogorov-Smirnov (KS) drift tests: Brightness (KS=0.42), RMS Contrast (KS=0.50), and Color channels (Red=0.83, Green=0.82, Blue=0.96).

    \vspace{3mm}
    \textcolor{TUMBlue}{\textbf{Fix:}} Standardize image collection protocols and apply color/intensity normalization to align visual characteristics.
  \end{tcolorbox}
\end{posterblock}
