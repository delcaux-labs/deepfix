% ---------------------- COLUMN 1: Why & How (0.24) --------------------------
\begin{column}{0.24\textwidth}

\begin{posterblock}[Motivation]
  \fontsize{28}{36}\selectfont\color{BodyText}\justifying
  Unlike traditional software, where failures are crashes or property violations, ML behavior is \emph{trained} via complex non-deterministic training:
  \vspace{4mm}
  \begin{itemize}[leftmargin=10mm, itemsep=8mm, label={\textcolor{TUMAccent}{\textbullet}}]
    \item \textbf{Failures lack explicit signals.} Models degrade gradually or show silent bias without stack traces or clear test oracles.
    \item \textbf{Testing is workflow-fragmented.} Quality assurance is split across disjoint data, training, and architecture checks; practitioners manually correlate clues, increasing cognitive load and trial-and-error debugging.
    \item \textbf{Checks are property- and model-bound.} Metamorphic tests, formal verification, and model-agnostic suites each cover only narrow property classes; often tied to specific algorithms or costly neural-network analyses.
    \item \textbf{Reports assume ML expertise.} Tools such as Deepchecks flag statistical violations in jargon that obscures root causes for practitioners.
    \item \textbf{Detection without remediation.} Bug reports state that issues exist but rarely suggest how to fix them.
  \end{itemize}
\end{posterblock}

\vspace{12mm}

\begin{highlightblock}[Research Question]
  \fontsize{30}{38}\selectfont\color{TUMDarkBlue}
  \centering\itshape
  Can we develop a unified approach that tests \textbf{all components of the ML workflow} (data, split, model) and provides a bug report with \textbf{actionable fix suggestions}?
\end{highlightblock}

\vspace{12mm}

\begin{column}{0.24\textwidth}

\begin{posterblock}[Industrial Case Study: Foodwaste classification]
  \fontsize{26}{32}\selectfont\color{BodyText}\justifying
  Validated in an industrial food waste image classification project at Delcaux Labs in partnership with \textbf{L. Stroetmann Großverbraucher GmbH \& Co. KG}. The underlying dataset is openly available on Hugging Face: \href{https://huggingface.co/datasets/AI-ServicesBB/food-waste-dataset}{\color{TUMBlue}\texttt{AI-ServicesBB/food-waste-dataset}}.

  DeepFix surfaced critical bugs that would have required extensive manual visual review to find:

  \vspace{4mm}
  \begin{tcolorbox}[
    enhanced, colback=white, colframe=SeverityCritical,
    boxrule=2pt, arc=4pt, left=8mm, right=8mm, top=5mm, bottom=5mm,
    title={\color{white}\fontsize{24}{28}\selectfont\bfseries CRITICAL --- Data Partitioning Failure},
    colbacktitle=SeverityCritical,
  ]
    \fontsize{22}{26}\selectfont
    \textbf{Evidence:} Combined evidence from Deepchecks surfaced that the label drift Cram\'{e}r's V\,=\,0.92 (far exceeding the 0.15 threshold) and 75\% of test set labels were entirely absent from training.

    \vspace{3mm}
    \textcolor{TUMBlue}{\textbf{Fix:}} Halt model development immediately and recreate the train--test split using stratified sampling.
  \end{tcolorbox}

  \vspace{4mm}

  \begin{tcolorbox}[
    enhanced, colback=white, colframe=SeverityHigh,
    boxrule=2pt, arc=4pt, left=8mm, right=8mm, top=5mm, bottom=5mm,
    title={\color{white}\fontsize{24}{28}\selectfont\bfseries HIGH --- Image Acquisition Drift},
    colbacktitle=SeverityHigh,
  ]
    \fontsize{22}{26}\selectfont
    \textbf{Evidence:} Multiple image properties failed Kolmogorov-Smirnov (KS) drift tests: Brightness (KS=0.42), RMS Contrast (KS=0.50), and Color channels (Red=0.83, Green=0.82, Blue=0.96).

    \vspace{3mm}
    \textcolor{TUMBlue}{\textbf{Fix:}} Standardize image collection protocols and apply color/intensity normalization to align visual characteristics.
  \end{tcolorbox}
\end{posterblock}

\vspace{10mm}

\begin{posterblock}[Limitations \& Next Steps]
  \fontsize{20}{25}\selectfont\color{BodyText}\justifying
  While DeepFix significantly accelerates ML workflow auditing:
  \vspace{3mm}
  \begin{itemize}[leftmargin=6mm, itemsep=2.5mm, label={\textcolor{TUMAccent}{\textbullet}}]
    \item \textbf{Limitations:} Relies primarily on Deepchecks for stage 1 checks (additional failure modes are expressible by extending the artifact schemas); introduces higher latency and compute costs than traditional linters due to multi-agent LLM analysis.
    \item \textbf{Grounding \& Compliance:} Data privacy is protected by supporting on-premise execution with self-hosted LLMs, ensuring sensitive artifacts never leave the organization.
    \item \textbf{Future Work:} Conduct a 30-participant usability study to measure the adoption rate of recommendations; expand the stage 1 analyzers with complementary unit-level and artifact-level testing tools; curate additional best practices in \texttt{deepfix-kb}.
  \end{itemize}
\end{posterblock}
