DeepFix uses a multi-agent system where specialized agents analyze different aspects of ML artifacts. Agent execution is orchestrated using **LangGraph**, dynamically dispatching analyzer nodes in parallel and synthesizing findings via a cross-artifact reasoning node.

## Agent Architecture

### LangGraph StateGraph Flow

```text
               ┌─────────────┐
               │    START    │
               └──────┬──────┘
                      │ (Dynamic conditional routing based on artifacts)
       ┌──────────────┼──────────────┬──────────────┐
       ▼              ▼              ▼              ▼
┌──────────────┐┌──────────────┐┌──────────────┐┌──────────────┐
│  Dataset     ││  Deepchecks  ││  Checkpoint  ││  Training    │
│  Analyzer    ││  Analyzer    ││  Analyzer    ││  Analyzer    │
└──────┬───────┘└──────┬───────┘└──────┬───────┘└──────┬───────┘
       │               │               │               │
       └───────────────┼───────────────┴───────────────┘
                       │ (Fan-In state merge)
                       ▼
         ┌───────────────────────────┐
         │ CrossArtifactReasoning    │
         │ (Grounded Synthesis)      │
         └─────────────┬─────────────┘
                       │
                       ▼
                  ┌─────────┐
                  │   END   │
                  └─────────┘
```

## Agent Types & Nodes

### DatasetArtifactsAnalyzer
**Purpose**: Analyze dataset statistics, distributions, anomalies, and class balance.
- **Input**: `DatasetArtifacts`
- **Output**: Structured findings on dataset quality, distribution shifts, and recommendations.
- **Execution**: Parallel LangGraph node.

### DeepchecksArtifactsAnalyzer
**Purpose**: Interpret Deepchecks reports for data validation, drift, and integrity issues.
- **Input**: `DeepchecksArtifacts`
- **Output**: Structured findings on data drift, train/test leakage, integrity checks, and recommendations.
- **Execution**: Parallel LangGraph node.

### ModelCheckpointArtifactsAnalyzer
**Purpose**: Validate model checkpoint integrity, configuration consistency, and deployment readiness.
- **Input**: `ModelCheckpointArtifacts`
- **Output**: Structured findings on checkpoint formats, architecture consistency, and readiness.
- **Execution**: Parallel LangGraph node.

### TrainingArtifactsAnalyzer
**Purpose**: Analyze training dynamics, loss curves, overfitting patterns, and convergence stability.
- **Input**: `TrainingArtifacts`
- **Output**: Structured findings on training stability, learning rate schedules, and optimization fixes.
- **Execution**: Parallel LangGraph node.

### CrossArtifactReasoningAgent
**Purpose**: Synthesize findings across all analyzer nodes into a holistic root-cause diagnosis.
- **Input**: Outputs from all active artifact analyzer nodes + optional `KnowledgeBridge` domain context.
- **Output**: Consolidated cross-artifact findings, prioritized actionable recommendations, and summary.
- **Execution**: Sequentially runs after all active analyzer nodes fan-in.

## StateGraph Implementation

### State Definition

```python
class AnalysisGraphState(TypedDict):
    context: AgentContext
    agent_results: Annotated[Dict[str, AgentResult], merge_agent_results]
    cross_artifact_result: Optional[AgentResult]
    errors: Annotated[List[str], merge_errors]
    summary: Optional[str]
```

### Graph Execution Sequence

1. Decode incoming `APIRequest` into `AgentContext`.
2. Initialize `AnalysisGraphState` with context.
3. LangGraph conditional router inspects available artifacts in `context` and spawns only relevant analyzer nodes in parallel.
4. Parallel analyzer nodes complete and their results are merged into `agent_results`.
5. `cross_artifact_reasoner` runs grounded synthesis using pre-fetched `KnowledgeBridge` context and previous analyses.
6. Return final `Result` to the API layer.

## Coordination

### DiagnosticSystem

The `DiagnosticSystem` manages graph initialization and execution:

```python
system = DiagnosticSystem(config=llm_config)
result = await system.arun(context)
```

## Knowledge Integration

### KnowledgeBridge

The cross-artifact reasoning node queries `KnowledgeBridge` for external best practices and ML troubleshooting playbooks:
- Web Search (Tavily)
- AI Research (Perplexity Sonar)
- Local KB domain documentation

Queries and retrieval results are automatically tracked in the agent result metadata and logged via MLflow.
