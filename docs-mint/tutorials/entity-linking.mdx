Information Retrieval (IR) and Entity Linking models match **Queries** (e.g., search terms or text mentions) against a large corpus of **Documents** or **Entities** to retrieve the most relevant candidates.

Evaluating and debugging these systems is uniquely challenging because they involve analyzing query-document pairs, relevance labels, and retrieval ranks or scores. DeepFix provides native support for this workflow via the `InformationRetrievalDataset` class and the `LlamaindexModel` wrapper, providing automated, detailed diagnostics for data quality, feature leakage, and retrieval performance.

## Prerequisites

- DeepFix SDK installed.
- DeepFix server running (local or remote).
- An API key if using the hosted DeepFix service.
- `pyterrier` installed (optional, used here to load candidate entities and queries).

## Setup

```python
import os
import pandas as pd
import numpy as np
import pyterrier as pt

from deepfix_sdk import DeepFixClient
from deepfix_sdk.ir import InformationRetrievalDataset, LlamaindexModel

# Set up your DeepFix API key
os.environ["DEEPFIX_API_KEY"] = "..."  # Insert your API key from DeepCoach

# Initialize the DeepFix client
client = DeepFixClient(
    api_url="https://deepfix.delcaux.com",
    timeout=300,
)
```

## Load and Prepare Dataset

For this tutorial, we load a subset of the **BEIR scidocs** dataset using `pyterrier`.

To successfully evaluate the retrieval model, we will:
1. Ingest queries (topics), ground-truth relevance labels (qrels), and document entities.
2. Prepare an `InformationRetrievalDataset` and split it into train and test splits.
3. Index corpus documents and generate real retrievals and embeddings using `LlamaindexModel`.

```python
def load_ir_data(subset_queries: int = 10, lancedb_index_dir: str = "./.lancedb"):
    """Load BEIR scidocs data using PyTerrier and prepare IR datasets with real LlamaindexModel retrievals."""
    name = "irds:beir/scidocs"
    dataset = pt.get_dataset(name)

    # 1. Get all topics and qrels, subset for fast execution
    all_topics = dataset.get_topics(variant="text")
    all_qrels = dataset.get_qrels()

    qid_subset = all_topics["qid"].unique()[:subset_queries]
    topics_df = all_topics[all_topics["qid"].isin(qid_subset)].copy()
    qrels_df = all_qrels[all_qrels["qid"].isin(qid_subset)].copy()

    needed_docnos = set(qrels_df["docno"].astype(str).unique())
    parent_corpus_iter = dataset.get_corpus_iter

    def subset_corpus_iter():
        count = 0
        for doc in parent_corpus_iter():
            if str(doc["docno"]) in needed_docnos:
                yield doc
                count += 1
                if count >= len(needed_docnos):
                    break

    # 2. Build a single dataset, then split using stratified sampling on labels
    ir_ds = InformationRetrievalDataset(
        dataset_name=name,
        topics=topics_df,
        enable_embedding_pca=True,
        embedding_pca_components=200,
        qrels=qrels_df,
        corpus_iter=subset_corpus_iter,
    )

    train_ir_ds, test_ir_ds = ir_ds.split(train_size=0.7, random_state=42)

    # 3. Generate real retrievals and embeddings using LlamaindexModel
    model = LlamaindexModel(
        dataset=ir_ds,
        load_if_exists=True,
        lancedb_index_dir=lancedb_index_dir,
        top_k=5,
        retrieval_mode="dense",
    )
    model.fit()
    train_ir_ds.set_predictions(model.retrieve_dataframe(train_ir_ds))
    test_ir_ds.set_predictions(model.retrieve_dataframe(test_ir_ds))

    # 4. Set embeddings for diagnostic suites using LlamaindexModel
    train_ir_ds.set_embeddings(model.get_embedding)
    test_ir_ds.set_embeddings(model.get_embedding)

    return train_ir_ds, test_ir_ds, lancedb_index_dir

# Load the train and test splits
train_data, test_data, lancedb_index_dir = load_ir_data(subset_queries=10)
```

## Define LlamaindexModel

DeepFix provides a `LlamaindexModel` wrapper that satisfies scikit-learn's estimator interface (implementing `fit`, `predict`, and `predict_proba`) over LlamaIndex retrieval workflows:

```python
# Initialize and fit the LlamaindexModel
model = LlamaindexModel(
    dataset=train_data,
    load_if_exists=True,
    lancedb_index_dir=lancedb_index_dir,
    top_k=5,
    retrieval_mode="dense",
)
model.fit()
model_name = "llamaindex"
```

## Run Diagnostics

Pass your datasets and model to the client to run the automated diagnostic suites:

```python
result = client.get_diagnosis(
    train_data=train_data,
    test_data=test_data,
    model=model,
    model_name=model_name,
    language="english",
)

# Print a text summary of all prioritized findings
print(result.to_text())
```

## Interpreting Findings

Typical findings surfaced for IR and Entity Linking systems include:

- **Task Mismatch**: Detecting whether data is labeled/structured as a simple text classifier when it should be modeled as Information Retrieval/ranking.
- **Label Leakage**: Identifying features derived from pre-computed scores or ranks that inadvertently leak the ground-truth relevance label (e.g., highly correlated similarity scores).
- **Non-functional Model Checkpoint**: Spotting if the model wrapper lacks underlying parameters/weights or does not access the proper lookup tables.
- **Dataset Scale**: Warning when the number of unique queries or overall sample size is critically low for training/evaluating robust retrieval models.
- **Class Imbalance**: Analyzing severe distribution skews between relevant (positive) and non-relevant (negative) candidate pairs.
- **Distribution Shift**: Detecting if candidate documents or query tokens shift significantly between the train and test splits.
